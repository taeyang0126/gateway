# 需求变更记录

## 记录规则
- 每次需求新增、变更、删除、延期都必须记录。
- 记录必须包含影响阶段、编号、原因、评审结论、计划完成时间。

## 模板
```
变更日期：
变更人：
变更类型：新增 / 修改 / 删除 / 延期
影响阶段：
需求编号：FR- / NFR- / AC-
变更说明：
变更原因：
影响分析：设计 / 开发 / 测试 / 发布
评审结论：通过 / 拒绝 / 待补充
计划完成时间：
```
