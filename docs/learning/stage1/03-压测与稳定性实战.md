# 阶段 1 压测与稳定性实战

## 1. 压测目标
阶段 1 的压测目标是验证网关在持续负载下的稳定性与可观测性，不只是跑出吞吐数字。

## 2. 压测入口与关键参数
- 脚本：`scripts/perf/stage1/run-stage1-ac4-local.sh`
- 默认时长：10 分钟
- 网关 JVM：默认 `-Xms2g -Xmx2g`
- 可覆盖参数：`GATEWAY_JVM_XMS`、`GATEWAY_JVM_XMX`

示例：
```bash
GATLING_HOME=/tmp/gatling-dist/gatling-charts-highcharts-bundle-3.15.0 \
./scripts/perf/stage1/run-stage1-ac4-local.sh \
  --duration-minutes 10 \
  --rps 2000 \
  --body-bytes 1024 \
  --output-dir reports/stage1/ac4-final
```

## 3. 结果产物说明
- `runtime-metrics.csv`：运行时采样
- `stability-summary.txt`：稳定性结论摘要
- `gateway-gc.log`：GC 观测日志
- `gatling-report.tgz`：压缩后的 HTML 报告
- `gatling-simulation.log.gz`：压缩后的 simulation log

## 4. 结果解读建议
- 先看失败率、超时率，再看吞吐和延迟分位。
- 对照 GC 日志判断是否有内存或停顿异常。
- 将结论回填到阶段证据文档，形成可审计闭环。
