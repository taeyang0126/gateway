# 阶段 1 学习导航

## 阶段目标
阶段 1 的目标是完成一个可运行、可测试、可压测、可追踪的 HTTP 反向代理最小闭环。

你需要掌握的不只是代码，还包括规范、质量门禁、压测与文档追踪流程。

## 建议学习顺序
1. `01-项目全景与架构.md`
2. `02-代码与规范实战.md`
3. `03-压测与稳定性实战.md`
4. `04-需求追踪与阶段Gate.md`
5. `05-CI与打包流水线.md`

## 阶段关键入口
- 模块说明：`gateway-server/README.md`
- 阶段设计：`docs/design/stage1/`
- 阶段 Gate：`docs/requirements/stage-gates/阶段1-Gate.md`
- 追踪矩阵：`docs/requirements/traceability/阶段1-需求追踪矩阵.tsv`
- 压测证据：`docs/requirements/evidence/stage1/T1-206-压测与稳定性报告.md`

## 本地必跑命令
```bash
./scripts/ci/run-quality.sh
./mvnw -pl gateway-server -am test
./scripts/requirements/verify-stage.sh 1 --strict
```

## 学习验收清单
- 能说清路由匹配、Host 策略、TraceId 策略。
- 能解释为什么要先删 Hop-by-Hop Header 再补 Forwarded 头。
- 能复现 10 分钟压测并读懂 `stability-summary.txt`。
- 能说明阶段 Gate 与追踪矩阵如何共同判定阶段完成。
