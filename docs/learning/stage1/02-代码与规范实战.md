# 阶段 1 代码与规范实战

## 1. 工程规范入口
- 质量规则目录：`codequality/`
- 本地统一入口：`./scripts/ci/run-quality.sh`
- 根构建配置：`pom.xml`

## 2. 当前质量门禁包含
- Spotless：格式一致性
- Checkstyle：编码规范与结构约束
- PMD：静态规则扫描
- SpotBugs：字节码缺陷扫描
- JaCoCo：覆盖率阈值检查

## 3. 编码实践要求（阶段 1）
- 依赖版本统一放在父工程 `pom.xml`。
- 模块日志使用 SLF4J 门面，不自造日志框架。
- 避免兼容性分叉代码，保持主路径清晰。
- 修改后必须补充对应单测，确保行为可回归验证。

## 4. 本地开发最小回归
```bash
./mvnw -pl gateway-server -am test
./scripts/ci/run-quality.sh
```

## 5. 常见问题排查
- `Spotless` 失败：先执行 `./mvnw spotless:apply` 再重跑。
- `JaCoCo` 阈值失败：优先补测试，不绕过门禁。
- `SpotBugs/PMD` 失败：先修真实问题，再考虑规则误报。
