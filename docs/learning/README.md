# Gateway 学习目录

这个目录用于按阶段组织学习资料，目标是让新成员通过文档可以完整掌握项目：
- 业务能力与代码实现
- 工程规范与质量门禁
- 压测方法、结果解读与复现实操
- 需求追踪、阶段 Gate、CI 流水线

## 学习方式
1. 先读阶段导航文档，明确学习目标和验收标准。
2. 再按专题文档学习代码、规范、压测、流程。
3. 最后按文档里的命令本地复现并自测。

## 分阶段目录
- `开发流程总览.md`：一份看懂“需求 -> 设计 -> 代码 -> 矩阵 -> Gate -> 校验”的统一手册
- `stage1/`：阶段 1 学习材料（HTTP 反向代理最小闭环）
  - 可视化流程页：[stage1/06-阶段1开发流程可视化.html](stage1/06-阶段1开发流程可视化.html)
  - 学习指导看板：[stage1/07-阶段1学习指导看板.html](stage1/07-阶段1学习指导看板.html)

## 双看板约束
- `06` 开发流程看板与 `07` 学习指导看板同级，同步要求一致。
- 需求/设计/实现变更时，两个看板都必须更新并通过 CI 校验。

## 学习完成判定
满足以下 3 条即可视为掌握当前阶段：
1. 能解释该阶段关键设计与主要权衡。
2. 能在本地独立执行质量校验、测试与压测命令并解释结果。
3. 能根据需求追踪矩阵定位“需求 -> 代码 -> 测试 -> 证据”链路。
