- 将阶段 1 需求拆分为可执行任务，建立严格依赖顺序。

```text

  -> T1-101 -> T1-102 -> T1-103 -> T1-104 -> T1-105 -> T1-106
  -> T1-107 -> T1-108 -> T1-109
  -> T1-201 -> T1-202 -> T1-203 -> T1-204 -> T1-205 -> T1-206
```

## 4. 可并行边界
- `T1-205` 完成后，可并行执行：
  - 压测报告模板准备（支撑 `T1-206`）
  - 追踪矩阵字段预填（支撑 `T1-301`）
- 除上述并行准备项外，阶段 1 主链保持串行，不跨越依赖提前编码。

## 5. 完成定义（DoD）
- 追踪矩阵中 `FR/NFR/AC` 全部映射到任务，并可更新为 `PASS`。
- 单元测试、集成测试通过，覆盖阶段 1 测试要求。
- 超时验收满足 `AC-1-3`（1s~1.2s）。
- 压测与稳定性满足 `AC-1-4` 与 `NFR-1-4`。
- 验收证据包含命令、报告、日志、代码定位，可复验。
