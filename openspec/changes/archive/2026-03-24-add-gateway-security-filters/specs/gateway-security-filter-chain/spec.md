## ADDED Requirements

### Requirement: 网关必须按固定顺序执行安全过滤器链
系统 MUST 在请求进入路由转发前，按以下顺序执行安全过滤器：真实 IP 解析、IP 访问控制、IP 限流、认证、用户限流。

#### Scenario: 执行顺序符合定义
- **WHEN** 网关收到命中路由的请求且所有过滤器均启用
- **THEN** 系统按定义顺序逐个执行过滤器且不允许跳序

#### Scenario: 任一过滤器拒绝后短路
- **WHEN** 请求在任一过滤阶段被判定为拒绝
- **THEN** 系统立即返回拒绝响应且不得进入上游转发流程

### Requirement: 网关必须支持全局与路由级安全配置组合策略
系统 SHALL 支持全局安全配置与路由级安全配置，并提供 `merge` 与 `replace` 两种组合策略。

#### Scenario: merge 组合继承全局未声明字段
- **WHEN** 路由级配置采用 `merge` 且仅声明部分字段
- **THEN** 系统仅覆盖路由声明字段并继承全局未声明字段

#### Scenario: replace 组合完整替换全局配置
- **WHEN** 路由级配置采用 `replace`
- **THEN** 系统对该路由使用路由级完整配置且不继承全局同类配置

### Requirement: 网关必须执行冻结的失败策略
系统 MUST 对认证与 IP 访问控制执行 `fail-closed`，并在分布式限流不可用时降级到本地限流。

#### Scenario: 认证执行异常时拒绝请求
- **WHEN** 认证过滤器在处理请求时发生执行错误或依赖不可用
- **THEN** 系统拒绝该请求并终止后续过滤阶段

#### Scenario: 分布式限流不可用时降级
- **WHEN** 限流模式为分布式且限流后端不可用
- **THEN** 系统自动切换到本地限流并继续执行限流判定
